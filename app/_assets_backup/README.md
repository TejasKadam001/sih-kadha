# Asset Backup Manifest

This folder contains all 31 unused, intermediate, or replaced media files that were removed from the active landing page to keep the repository clean and optimized.

## How to Restore

- **To restore ALL files**:
  Run `./_assets_backup/RESTORE_ALL.sh` from the repository root, or tell your AI assistant in your next prompt: `"restore all backed up assets"`.

- **To restore an individual file**:
  Simply copy it from its subfolder back to its original location (listed in `RESTORE_ALL.sh`).

## Folders
1. `raw_user_uploads/`: Original raw images uploaded during development (e.g. `k01.png`, `Triphala & Guduchi Side-by-Side.png`).
2. `old_medicine_jars/`: Old apothecary jar product mockups replaced by coffee pods.
3. `unused_graphics_and_crops/`: Intermediate vector SVGs, test crops, duplicate copies, and temporary frames.
